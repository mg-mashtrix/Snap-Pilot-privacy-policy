## 1. Introduction

SnapPilot is a Chrome extension built for users who need a simple, fast, and practical way to capture, explain, and share visual information from their browser or screen.

Whether you are creating product documentation, reporting bugs, recording tutorials, preparing walkthroughs, capturing long web pages, extracting text from screenshots, or saving visual references for later, SnapPilot brings these workflows together in one browser-based tool.

With SnapPilot, you can capture screenshots, record tabs or screens, annotate images and videos, blur sensitive information, generate microphone-based subtitles, use a camera overlay, display a teleprompter script, extract text using OCR, and manage saved captures in a local gallery.

SnapPilot is designed with a local-first approach. Screenshots, recordings, OCR processing, gallery items, teleprompter text, and user preferences are handled locally in the browser or device wherever possible. Captured content is not uploaded to SnapPilot servers.

## 6. Screenshot Capture

SnapPilot supports multiple screenshot modes.

### 6.1 Visible Area Capture

Visible Area Capture captures only the currently visible part of the active browser tab.

Use this when you want a quick screenshot of what is currently on screen.

#### Steps

1. Open the page you want to capture.
2. Click the SnapPilot extension icon.
3. Choose **Visible Area**.
4. SnapPilot captures the visible part of the tab.
5. The capture opens in the editor or follows your configured setting.

---

### 6.2 Region Capture

Region Capture allows you to select a specific part of the page.

Use this when you only want to capture a specific section, card, modal, form, dashboard area, or error message.

#### Steps

1. Open the page you want to capture.
2. Click the SnapPilot extension icon.
3. Choose **Region Capture**.
4. Drag over the area you want to capture.
5. Release the mouse to confirm the region.
6. The selected area is captured and opened in the editor.

---

### 6.3 Full-Page Capture

Full-Page Capture captures the entire scrollable page by scrolling and stitching the content.

Use this when you want to capture a complete webpage, article, dashboard, or long page.

#### Steps

1. Open the page you want to capture.
2. Click the SnapPilot extension icon.
3. Choose **Full Page**.
4. Wait while SnapPilot scrolls and captures the full page.
5. The final stitched screenshot opens in the editor.

---

### 6.4 Inner Scroller Capture

Some web apps contain scrollable panels inside the page. Examples include CRMs, dashboards, inboxes, side panels, tables, modals, or app containers.

SnapPilot can detect and capture inner scrolling areas.

#### Steps

1. Open the target page or application.
2. Click the SnapPilot extension icon.
3. Choose the appropriate full-page or inner-scroll capture option.
4. If SnapPilot detects multiple scrollable areas, select the correct one.
5. SnapPilot captures and stitches the selected scrolling area.

## 17. Troubleshooting

### 17.1 Screenshot Does Not Capture Correctly

Try the following:

* Refresh the page and try again.
* Make sure the active tab is not a restricted Chrome page.
* Try visible capture instead of full-page capture.
* For web apps with inner scrolling areas, use inner scroller capture.
* Check if the page has lazy-loaded content that appears only after scrolling.

---

### 17.2 Full-Page Capture Misses Content

Possible causes:

* The page uses virtual scrolling.
* The page loads content dynamically.
* The page has fixed headers or sticky elements.
* The page has multiple scroll containers.
* The page blocks scripted scrolling.

Try:

* Increasing scroll delay in settings.
* Using inner scroller capture.
* Capturing smaller regions.
* Capturing visible sections manually.

---

### 17.3 Recording Has No Audio

Check the following:

* Make sure microphone is enabled if you need voice audio.
* Make sure Chrome has microphone permission.
* Make sure the correct microphone is selected in Chrome or system settings.
* Window or desktop recording may not always include system audio depending on Chrome and operating system behavior.
* Tab recording may be more reliable for tab audio where supported.

---

### 17.4 Subtitles Are Not Generated

Check the following:

* Make sure microphone is enabled.
* Make sure Chrome has microphone permission.
* Speak clearly near the microphone.
* Check the selected subtitle language.
* Browser speech recognition availability may vary.
* Subtitles are microphone-based and may not capture system audio directly.

---

### 17.5 Camera Overlay Does Not Appear

Try the following:

* Make sure camera overlay is enabled.
* Make sure Chrome has camera permission.
* Make sure no other app is exclusively using the camera.
* Check camera device settings.
* Restart recording after granting permission.

---

### 17.6 Teleprompter Does Not Stay on Top

SnapPilot is a Chrome extension, not a native desktop app.

Browser windows may not always stay above all other applications. Always-on-top behavior depends on Chrome, the operating system, and browser limitations.

---

### 17.7 Soft Mode Is Not Fully Transparent

True operating-system-level transparency may not be available for Chrome extension windows.

Soft mode is intended as a visual reading mode within browser limitations, not a native transparent overlay.

---

### 17.8 Gallery Items Are Missing

Possible causes:

* Browser storage was cleared.
* Extension data was removed.
* The extension was uninstalled or reset.
* Chrome profile changed.
* The user is using a different Chrome profile.

Gallery data is stored locally.

## 21. Frequently Asked Questions

### Q1. Does SnapPilot upload my screenshots or recordings?

No. SnapPilot is designed to process captures locally. Screenshots, recordings, OCR output, gallery items, and settings are not uploaded to SnapPilot servers.

### Q2. Does SnapPilot sell user data?

No. SnapPilot does not sell user data.

### Q3. Can SnapPilot record my screen in the background?

No. Recording starts only after user action and browser permission or source selection where required.

### Q4. Why do subtitles require microphone access?

SnapPilot subtitles are generated from microphone input. If microphone is off, subtitles may not work.

### Q5. Can subtitles transcribe system audio?

Not reliably. Subtitles are microphone-based and may not capture system audio, tab audio, or meeting audio unless those sounds are captured through the microphone.

### Q6. Does SnapPilot read my clipboard?

No. SnapPilot may write screenshots or edited images to the clipboard when the user chooses a copy action, but it does not read clipboard content.

### Q7. Where are gallery items stored?

Gallery items are stored locally in the browser or device using browser-provided storage.

### Q8. Why does the teleprompter not behave like a native transparent overlay?

Chrome extension windows do not always support true operating-system-level transparency, click-through behavior, or always-on-top behavior. SnapPilot’s teleprompter works within browser limitations.

### Q9. Can I edit saved gallery items?

Yes. Images can be opened in the Image Editor, and videos can be opened in the Video Editor where supported.

### Q10. Can I delete saved captures?

Yes. You can delete saved screenshots or recordings from the local gallery.
