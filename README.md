# Privacy Policy for SnapPilot

**Effective Date:** 29-05-2026  
**Product Name:** SnapPilot  
**Publisher:** Mashtrix Technologies  
**Contact:** hello@mashtrixx.com  

## 1. Introduction

SnapPilot is a Chrome extension that helps users capture screenshots, record screens, annotate images and videos, extract text from screenshots using OCR, manage captures in a local gallery, use a teleprompter helper, optionally add a camera overlay to recordings, and optionally generate microphone-based subtitles.

This Privacy Policy explains what information SnapPilot accesses, how that information is used, where it is stored, and what choices users have.

By using SnapPilot, you agree to the practices described in this Privacy Policy.

## 2. Information SnapPilot May Access or Process

SnapPilot may access or process the following information only when required for a user-requested feature.

### 2.1 Screenshot Content

When you use visible capture, region capture, full-page capture, or inner scroller capture, SnapPilot processes the visible page content required to create the screenshot.

### 2.2 Screen, Window, or Tab Recording Content

When you start a recording, SnapPilot processes the selected screen, window, browser tab, or selected region that you choose through the browser’s screen sharing prompt or SnapPilot’s recording controls.

Screen recording starts only after user action. SnapPilot does not record in the background without the user starting a recording.

### 2.3 Video Recording Content

SnapPilot may process video recordings created through the extension so users can preview, trim, annotate, export, download, or save them to the local gallery.

### 2.4 Microphone Audio

If you enable microphone recording, SnapPilot may capture microphone audio and include it in the recording.

Microphone access is optional and is used only when the user enables microphone-related features.

### 2.5 Subtitles and Captions

If you enable subtitles, SnapPilot may use microphone input to generate captions. Subtitles depend on microphone input and may not reliably transcribe system audio, tab audio, meeting audio, or other audio sources unless those sounds are captured through the microphone.

Subtitle and caption data may be used to display captions during recording, preview, editing, or export.

### 2.6 Camera Video

If you enable the camera overlay feature, SnapPilot may access your camera and include your camera feed as an overlay in the recording.

Camera access is optional and is used only when the user enables camera-related recording features.

### 2.7 Annotation Data

When you edit a screenshot or video, SnapPilot may process or store annotation information such as shapes, arrows, text, colors, stroke width, blur areas, highlights, counters, drawing positions, caption settings, timing data, and other editing metadata.

### 2.8 OCR Text

When you use text extraction, SnapPilot processes the selected screenshot or image locally to detect and extract text. OCR output may include text visible in the screenshot selected by the user.

### 2.9 Teleprompter Script Text

If you use the teleprompter feature, SnapPilot may process the script text you enter so it can be displayed in the teleprompter helper window.

Teleprompter text is used only for the teleprompter feature.

### 2.10 Local Gallery Data

If you save screenshots or recordings to the gallery, SnapPilot stores those files and related metadata locally in your browser or device so you can view, edit, download, or delete them later.

### 2.11 Extension Settings and Preferences

SnapPilot stores user preferences such as capture format, image format, scroll delay, auto-save preference, copy preference, default annotation color, stroke width, shortcut preferences, recording options, microphone preference, subtitle settings, camera overlay settings, teleprompter settings, theme, and other extension preferences.

## 3. How SnapPilot Uses Information

SnapPilot uses accessed information only to provide the features requested by the user, including:

- Capturing visible screenshots
- Capturing selected regions
- Capturing full-page screenshots
- Capturing inner scrolling areas
- Recording screens, windows, tabs, or selected regions
- Previewing recordings
- Opening captures in the editor
- Adding screenshot annotations
- Adding video annotations
- Trimming or exporting videos
- Displaying or exporting captions
- Extracting text from screenshots using OCR
- Copying screenshots or edited images to the clipboard
- Downloading images, PDFs, or recordings
- Saving captures in the local gallery
- Opening saved images or videos in the editor
- Displaying teleprompter script text
- Adding camera overlay to recordings
- Recording microphone audio when enabled
- Generating microphone-based subtitles when enabled
- Restoring user settings and preferences

SnapPilot does not use captured content for advertising, profiling, analytics, resale, or unrelated purposes.

## 4. Local Processing

SnapPilot is designed as a local-first extension.

Screenshots, recordings, annotations, OCR processing, gallery storage, teleprompter text, camera overlay processing, microphone audio processing, subtitles, captions, and settings are handled locally in the user’s browser or device wherever possible.

SnapPilot does not upload screenshots, recordings, OCR output, microphone audio, camera video, teleprompter text, subtitles, captions, or gallery content to our servers.

OCR is performed using locally bundled OCR files included with the extension package.

## 5. Data Storage

SnapPilot stores data locally in the browser using browser-provided storage such as extension storage and local browser databases.

Stored data may include:

- User settings
- Saved screenshots
- Saved recordings
- Gallery metadata
- Annotation information
- Video editing metadata
- Caption or subtitle metadata
- Teleprompter preferences
- OCR results, if saved as part of a capture workflow

This data remains on the user’s device unless the user chooses to copy, download, export, share, upload, or otherwise transfer it outside SnapPilot.

## 6. Clipboard Access

If the user enables copy features, SnapPilot may write a screenshot or edited image to the system clipboard.

Clipboard writing happens only as part of a user-facing capture or editor action. SnapPilot does not read the user’s clipboard.

## 7. Downloads

When the user downloads a screenshot, PDF, or recording, SnapPilot uses Chrome’s download functionality to save the file selected by the user.

SnapPilot does not track downloaded files after they are saved.

## 8. Screen Recording

Screen recording starts only after the user selects or confirms a screen, window, tab, or recording mode through browser or extension controls.

SnapPilot does not record in the background without user action. Recording stops when the user stops the recording, closes the recording source, revokes browser sharing, or the stream ends.

## 9. Microphone, Camera, and Subtitle Behavior

Microphone and camera access are optional.

If subtitles are enabled while microphone recording is off, SnapPilot may ask the user to enable the microphone because subtitles require microphone input. If the user does not allow microphone access or chooses not to enable the microphone, subtitles may not work or may remain disabled.

Subtitles are provided as a convenience feature and may be limited by browser speech recognition availability, microphone quality, language support, background noise, and browser behavior.

Camera overlay is used only when the user enables camera-related recording features.

## 10. Teleprompter Behavior and Limitations

SnapPilot may provide a floating teleprompter helper window for displaying user-provided script text.

Due to browser and operating system limitations, a Chrome extension window may not support true operating-system-level transparent, click-through, or always-on-top overlay behavior in all cases.

Any “Soft” or visual teleprompter mode is intended to improve readability and reduce distraction within browser limitations. It should not be understood as a native desktop-level transparent overlay.

## 11. Data Sharing

SnapPilot does not sell, rent, trade, or share user data with third parties.

SnapPilot does not transfer screenshots, recordings, OCR text, annotations, microphone audio, camera video, subtitles, captions, teleprompter text, or gallery data to external servers.

Data may leave the local browser only when the user manually performs an action such as:

- Copying a screenshot or edited image
- Downloading a file
- Exporting a PDF
- Exporting a video
- Sharing a saved capture
- Uploading a downloaded file to another service outside SnapPilot

## 12. Third-Party Services and Libraries

SnapPilot does not rely on third-party servers for screenshot capture, screen recording, annotation, OCR processing, teleprompter text, microphone audio processing, camera overlay processing, subtitle handling, or gallery storage.

SnapPilot may include open-source libraries bundled locally with the extension package. These libraries run inside the browser and are not loaded from a remote CDN.

## 13. Remote Code

SnapPilot does not use remotely hosted executable code.

JavaScript, workers, WebAssembly files, OCR files, language files, and other extension assets required by the extension are bundled with the extension package.

## 14. Permissions Used

SnapPilot may request Chrome permissions required for its features, including:

### activeTab

Used to capture or interact with the active tab after the user starts a capture action.

### scripting

Used to show capture overlays, region selection tools, and scrolling helpers on the active page.

### tabs

Used to open the editor, recorder, gallery, and communicate between extension pages and the active tab.

### windows

Used to open or manage extension windows such as recorder, helper, gallery, editor, or teleprompter windows.

### storage

Used to save settings, gallery data, and user preferences locally.

### downloads

Used when the user downloads screenshots, PDFs, or recordings.

### offscreen

Used for image processing, stitching, OCR, recording support, and related background processing.

### clipboardWrite

Used when the user chooses to copy screenshots or edited images to the clipboard.

### desktopCapture

Used to allow the user to record a selected screen, window, or tab.

### tabCapture

Used, where applicable, to capture or record browser tab content when the user starts a tab recording.

### contextMenus

Used, where applicable, to provide quick access to SnapPilot capture or recording actions from the browser context menu.

### Microphone Access

Used only when the user enables microphone recording or microphone-based subtitles.

### Camera Access

Used only when the user enables the camera overlay feature.

SnapPilot requests these permissions only to provide the features described in this Privacy Policy and in the Chrome Web Store listing.

## 15. User Control

Users can control their data by:

- Choosing when to start screenshots or recordings
- Choosing which screen, window, tab, or region to record
- Enabling or disabling microphone recording
- Enabling or disabling subtitles
- Enabling or disabling camera overlay
- Editing, downloading, copying, exporting, or deleting captures
- Deleting screenshots or recordings from the gallery
- Clearing gallery data where the extension provides that option
- Disabling auto-save
- Disabling copy after capture
- Changing extension settings
- Removing the extension from Chrome
- Clearing browser extension storage through Chrome settings

Uninstalling the extension may remove locally stored extension data, depending on Chrome’s storage behavior.

## 16. Children’s Privacy

SnapPilot is a general productivity tool. It is not designed specifically for children and does not knowingly collect personal information from children.

## 17. Security

SnapPilot is designed to minimize data exposure by processing captures locally and avoiding remote upload of user content.

SnapPilot follows Chrome extension security practices such as using Manifest V3, avoiding remote executable code, and keeping extension assets bundled locally.

However, users should avoid capturing, recording, exporting, or sharing sensitive information unless they are comfortable storing or transferring that content on their own device. Users are responsible for ensuring they have permission to capture or record any content, meetings, windows, pages, or screens.
